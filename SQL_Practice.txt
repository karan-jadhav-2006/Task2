### 🎓 College Management

24. Create a `CollegeStudent` table with suitable constraints and datatypes.

CREATE TABLE CollegeStudent (
    student_id INT PRIMARY KEY,
    student_name VARCHAR(50) NOT NULL,
    age INT CHECK (age >= 17),
    email VARCHAR(100) UNIQUE,
    phone_no BIGINT UNIQUE,
    course VARCHAR(50) NOT NULL,
    city VARCHAR(30),
    fees DECIMAL(10,2) CHECK (fees >= 0),
    admission_date DATE NOT NULL,
    status VARCHAR(20) DEFAULT 'Active'
);

25. Display the **top 5 students** according to marks using `ORDER BY` and `LIMIT`.

    select * from CollegeStudent ORDERBY DESC LIMIT 5;

26. Skip the first 5 students and display the next 5 students using `LIMIT` and `OFFSET`.
  
    select * from CollegeStudent LIMIT 5 OFFSET 5;


27. Display student names with the column heading **"Student Name"** using an alias.

    select name As Student_name from CollegeStudent;
